# Quick Start Guide

## 1분 안에 시작하기

### Windows
```bash
start.bat
```

### Mac/Linux
```bash
chmod +x start.sh
./start.sh
```

브라우저가 자동으로 열립니다: **http://localhost:8000**

---

## 첫 번째 프로세스 실행

### Step 1: 프로세스 로드
1. 드래그앤드롭 영역에 `samples/processes/onboarding.json` 파일을 끌어다 놓기
   - 또는 "프로세스 로드" 버튼 클릭 후 파일 선택

### Step 2: 정보 입력
**단계 1/4 - 개인정보 입력**
- ✅ 체크리스트 2개 체크
- 📝 이름: "홍길동"
- 📝 이메일: "hong@example.com"
- 📝 전화번호: "010-1234-5678"
- 📅 입사일: 오늘 날짜 선택
- ➡️ "다음" 버튼 클릭

**단계 2/4 - 서류 제출**
- ✅ 체크리스트 1개 체크
- 📎 이력서 업로드 (PDF 또는 DOCX, 10MB 이하)
- 📎 증명사진 업로드 (JPG, PNG, 5MB 이하)
- ➡️ "다음" 버튼 클릭

**단계 3/4 - 계정 설정**
- ✅ 체크리스트 1개 체크
- 📝 사번: "EMP-2026-001"
- 📝 부서: "개발팀"
- ➡️ "다음" 버튼 클릭

**단계 4/4 - 완료**
- 🎉 완료 메시지 확인
- 📦 "ZIP 내보내기" 버튼 클릭

### Step 3: 결과 확인
- `PROC-20260104-0001_2026-01-04.zip` 파일 다운로드
- ZIP 파일 내용:
  - `process.json` - 프로세스 템플릿
  - `progress.json` - 진행 상황
  - `logs.json` - 변경 이력
  - `files/` - 업로드한 파일들

## 추가 기능 테스트

### 여러 프로세스 로드
1. "프로세스 로드" 버튼 클릭
2. `samples/processes/expense-report.json` 로드
3. 사이드바에서 프로세스 전환 가능

### AI 챗봇 사용
1. 우측 하단 💬 버튼 클릭
2. LibreChat 슬라이드 패널 열림
3. 프로세스 관련 질문 가능
4. ESC 키로 닫기

### 진행 상황 추적
- **추적 정보 카드** (상단): 담당자, 부서, 상태, 마감일
- **진행률 바**: 전체 진행률 (0-100%)
- **단계 표시기**: 현재/전체 단계

## 파일 업로드 규칙

### 이력서/자기소개서
- **형식**: PDF, DOCX
- **최대 크기**: 10MB
- **검증**: 형식 및 크기 자동 체크

### 이미지 (증명사진 등)
- **형식**: JPG, JPEG, PNG
- **최대 크기**: 5MB
- **검증**: 형식 및 크기 자동 체크

### 영수증/세금계산서
- **형식**: PDF, JPG, JPEG, PNG
- **최대 크기**: 10MB
- **검증**: 형식 및 크기 자동 체크

## 자주 묻는 질문

### Q: 프로세스를 중단하고 나중에 다시 시작할 수 있나요?
A: 네, 모든 진행 상황은 IndexedDB에 자동 저장됩니다. 브라우저를 닫았다가 다시 열어도 진행 상황이 유지됩니다.

### Q: 이전 단계로 돌아갈 수 있나요?
A: 네, "이전" 버튼을 클릭하면 언제든지 이전 단계로 돌아갈 수 있습니다.

### Q: 필수 항목을 건너뛸 수 있나요?
A: 아니요, 필수 체크리스트와 필수 필드를 모두 완료해야 다음 단계로 진행할 수 있습니다.

### Q: 업로드한 파일은 어디에 저장되나요?
A: 브라우저의 IndexedDB에 저장됩니다. 서버로 전송되지 않으며, ZIP 내보내기 후 수동으로 제출해야 합니다.

### Q: 여러 프로세스를 동시에 진행할 수 있나요?
A: 네, 사이드바에서 프로세스를 전환하며 여러 프로세스를 관리할 수 있습니다.

## 문제 해결

### 프로세스가 로드되지 않음
- JSON 파일 형식 확인 (필수 필드: id, name, version, steps)
- 브라우저 콘솔(F12)에서 오류 메시지 확인

### 파일 업로드 실패
- 파일 크기 확인 (10MB 이하 권장)
- 파일 형식 확인 (accept 속성)
- 브라우저 저장 공간 확인

### 진행 상황이 저장되지 않음
- 브라우저가 IndexedDB를 지원하는지 확인
- 시크릿 모드 사용 중인지 확인 (저장소 제한 있음)
