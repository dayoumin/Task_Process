# Quick Start - 5분 안에 첫 프로세스 만들기

## 1단계: 서버 실행 (30초)
```bash
# Windows
start.bat

# Mac/Linux
./start.sh
```
→ http://localhost:5174 자동 열림

## 2단계: 노드 추가 (1분)
1. **시작** 버튼 클릭 (녹색)
2. **작업** 버튼 클릭 (파란색)
3. **완료** 버튼 클릭 (빨간색)

## 3단계: 노드 연결 (30초)
- 시작 노드 하단 → 작업 노드 상단으로 드래그
- 작업 노드 하단 → 완료 노드 상단으로 드래그

## 4단계: 작업 노드 편집 (2분)
1. 작업 노드 클릭
2. 사이드바에서 편집:
   - 제목: "문서 제출"
   - 설명: "필요한 문서를 업로드하세요"
   - 체크리스트 추가: "문서 확인 완료" (필수)
   - 필드 추가:
     - 파일 버튼 클릭
     - 라벨: "문서 파일"
     - 필수 체크

## 5단계: 추적 관리 설정 (1분)
사이드바에서 입력:
- 부서: 인사팀
- 담당자 ID: "생성" 버튼 클릭
- 담당자 이름: "홍길동"
- 우선순위: 보통
- 마감일: 오늘 + 7일

## 6단계: JSON 내보내기 (10초)
- 상단 **JSON 내보내기** 버튼 클릭
- 파일 다운로드 완료!

---

## 생성된 JSON 파일은?
- User Executor에서 바로 실행 가능
- `user-executor/samples/processes/` 폴더에 복사
- 실제 업무 프로세스로 사용
